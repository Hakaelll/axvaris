# Relief basemap

`earth-relief.jpg` is NASA Earth Observatory's Blue Marble Next Generation global image for January 2004, with topographic and bathymetric shading. Its original raster pixels remain unchanged. The JPEG comment records the source; the interface applies neutral tones while rendering it.

- Source description: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/
- Original image: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-topography-bathymetry/january/world.topo.bathy.200401.3x5400x2700.jpg
- Dimensions: 5400 × 2700 pixels.
- Registration: equirectangular, longitude −180° to 180° left to right and latitude 90° to −90° top to bottom.
- Media use: https://www.nasa.gov/nasa-brand-center/images-and-media/

This is an offline basemap, not current imagery or connection evidence. The SVG map and Three.js globe render authoritative atlas boundaries and actual connection markers separately. The application makes no request to NASA at runtime.
