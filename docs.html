Ejecutable portable

Sin instalación

El portable ejecuta la misma aplicación sin crear una entrada de instalación. Windows necesita WebView2, presente normalmente en Windows 10/11 actualizado. 

Get-FileHash -Algorithm SHA256 .\Sabicheiro-0.4.2-windows-x64-portable.exe

La aplicación y el observador normal se ejecutan como el usuario actual. ETW y Pktmon pueden requerir una sesión aprobada con más permisos; la interfaz completa no se eleva automáticamente.

i
Datos y desinstalación

La base de datos, ajustes y logs residen en %APPDATA%\io.sabicheiro.desktop\. El ciclo NSIS validado elimina el programa y el acceso de Inicio, pero conserva esos datos para evitar una pérdida accidental. Puedes borrarlos desde Datos y estado o manualmente después de cerrar Sabicheiro.

Usar un paquete construido y verificado

APPIMAGE

Aplicación portable

Verifica el checksum, marca el archivo como ejecutable y ábrelo como usuario normal. 

sha256sum ./Sabicheiro*.AppImage
chmod +x ./Sabicheiro*.AppImage
./Sabicheiro*.AppImage
DEB

Debian / Ubuntu

Instala el paquete local con el gestor del sistema para resolver dependencias. 

sha256sum ./Sabicheiro*.deb
sudo apt install ./Sabicheiro*.deb

Construir nativamente en Debian o Ubuntu

Tauri genera paquetes nativos; no se deben presentar como validados paquetes Linux cruzados desde Windows. Instala Rust estable, Node.js 22+, pnpm 11 y los prerrequisitos del sistema: 

sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev patchelf

pnpm install --frozen-lockfile
pnpm tauri build --bundles appimage,deb

Los resultados se generan bajo target/release/bundle/appimage/ y target/release/bundle/deb/. Fedora y Arch necesitan los paquetes equivalentes de WebKitGTK, AppIndicator, OpenSSL y herramientas de compilación.

Origen trazable

Cómo observa la red

Socket observation y packet recording son funciones separadas.

La observación normal recopila metadatos de sockets y procesos. La grabación completa de paquetes solo empieza tras una acción explícita y escribe un archivo PCAPNG elegido por el usuario. Sabicheiro nunca necesita capturar payload para construir su vista principal.

A

Windows: IP Helper + ETW opcional

IP Helper aporta endpoints TCP/UDP y PID. ETW puede añadir eventos breves, DNS y deltas de bytes/paquetes, pero su acceso depende de la política del sistema. Si se deniega, IP Helper continúa activo.

B

Linux: INET_DIAG + /proc

Netlink obtiene sockets IPv4/IPv6; los inodes se correlacionan con PID a través de /proc. La conexión no se descarta cuando el proceso desaparece o no es visible.

C

Evidencia inmutable

SQLite v5 conserva observaciones con reloj del proveedor, secuencia, huecos, procedencia por campo y proyecciones reproducibles. La retención puede ser Off, 1, 7, 30, 90 días o ilimitada.

D

Correlación explicable

PID, instancia de proceso, DNS, interfaz, ruta y GeoIP indican su fuente y calidad: confirmado, correlacionado, candidato, snapshot o no disponible.

×
Sabicheiro no es un antivirus ni un firewall

No bloquea conexiones, no ejecuta comandos, no consulta reputación en la nube y no convierte un listener wildcard en una afirmación de exposición a Internet. Presenta evidencia para que la persona decida.

Investigaciones portables .sabi

Un archivo .sabi es un ZIP versionado con conjunto exacto de entradas, límites de tamaño, CRC y hashes SHA-256. La importación se abre en un espacio de solo lectura, no se mezcla con el historial local y falla si cambia un solo byte. Antes de exportar puedes redactar IP locales, usuarios, rutas y nombres sensibles.

Metadatos e investigaciones

  • CSV o JSON por consulta, rango temporal o sesión
  • .sabi verificado y opcionalmente redactado

Grabación PCAPNG

  • Pktmon en Windows; dumpcap en Linux
  • Límite de 1 a 4096 MiB y hasta 24 horas
  • Modo circular o rotación acotada a cuatro archivos
  • No sobrescribe una captura existente
!
Un PCAPNG puede contener información sensible

La monitorización normal no conserva payload. La grabación sí puede incluir contenido completo de paquetes; protege el archivo, limita su duración y compártelo solo después de revisarlo.

Sin promesas falsas

Limitaciones conocidas

Qué no puede observarse con certeza y por qué.

Área Windows Linux Comportamiento seguro
Conexiones muy breves IP Helper puede perderlas si ETW está denegado. Un snapshot INET_DIAG también puede no verlas. Se informa el proveedor y no se afirma cobertura completa.
UDP remoto La tabla base solo expone binds; ETW puede aportar peers. INET_DIAG no equivale a un flujo de eventos completo. No presenta 0.0.0.0:0 como destino inventado.
Bytes por conexión Solo con eventos ETW aceptados. No los suministra el snapshot base. Los totales de interfaz se muestran aparte.
Proceso Permisos y carreras de PID pueden ocultarlo. hidepid, namespaces y otros usuarios pueden ocultarlo. Conserva el endpoint como “Proceso desconocido”.
GeoIP y DNS GeoIP es aproximado y requiere dataset local; DNS inverso es opcional y puede exponer la consulta al resolver. No dibuja coordenadas inventadas; muestra “Ubicación desconocida”.
Firewall / exposición El ámbito del bind no demuestra accesibilidad desde Internet; el proveedor nativo de reglas sigue pendiente. Exposure muestra evidencia y limitación, no un veredicto.
Eventos avanzados Despliegue elevado del helper y ETW todavía en revisión. eBPF de producción y fixtures nativos pendientes. Fallback automático al observador normal disponible.
Validación de lanzamiento Ocho horas, Narrator/NVDA y matriz HiDPI pendientes. Además faltan AppImage/deb, permisos y namespaces nativos. La versión conserva la etiqueta de candidato.
Diagnóstico

Resolver problemas

Empieza siempre por Datos y estado: allí aparece la fuente activa.

No aparece ninguna conexión

Elige Todas las interfaces, confirma que la interfaz está activa y revisa el proveedor en Datos y estado. Prueba Demo para separar un problema de interfaz de un problema de captura. En Linux, no ejecutes la UI como root: revisa permisos de /proc y Netlink.

Faltan destinos UDP o contadores por conexión

Es una limitación normal del proveedor de snapshots. En Windows, ETW puede completar esos datos si la sesión está permitida. Los totales de subida y bajada del dispositivo son reales, pero nunca se reparten entre flujos sin evidencia.

El mapa no muestra ciudades o países

Instala o importa una base DB-IP City Lite desde Datos y estado. La aplicación funciona sin ella, mantiene las IP y muestra ubicación desconocida. Los mapas no usan tiles remotos.

El globo está vacío o funciona lentamente

Comprueba WebGL en WebView2 o WebKitGTK y cambia a mapa 2D. También puedes usar densidad compacta, reducir movimiento y desactivar el enfoque automático. La vista accesible del feed conserva toda la evidencia.

Exposure no carga un snapshot antiguo

La vista descarta registros malformados sin cerrar la aplicación, evita respuestas IPC antiguas y ofrece recarga si un render falla. Si SQLite devuelve un error, abre Datos y estado, ejecuta la comprobación de integridad y exporta un bundle de soporte revisado.

La grabación de paquetes falla

En Windows confirma que Pktmon existe y que el contexto tiene permisos. En Linux instala dumpcap y configura el grupo de captura o capacidades mínimas de tu distribución. Elige una ruta nueva terminada en .pcapng; Sabicheiro no sobrescribe archivos existentes.

El paquete Linux no compila

Instala WebKitGTK 4.1, AppIndicator, OpenSSL, librsvg, libxdo y patchelf. Compila en Linux nativo, no desde Windows. Fedora y Arch usan nombres de paquete distintos a Debian/Ubuntu.
